# Day 2 - Student Data Analysis

## Project Description

This project was developed as part of the **HisabDo AI/ML Internship - Day 2 Task**.

The purpose of this project is to practice Python programming, data handling, and the Pandas library by creating a simple student data analysis application.

The program stores information for 10 students, converts the data into a Pandas DataFrame, and performs basic data analysis.

---

## Objectives

- Learn Python data structures
- Work with dictionaries and lists
- Use the Pandas library
- Create a DataFrame
- Perform filtering and calculations
- Display useful information from the dataset

---

## Features

- Store information for 10 students
- Display all students
- Display students with marks greater than 70
- Calculate average marks
- Find the student with the highest marks
- Find the student with the lowest marks
- Display the total number of students

---

## Technologies Used

- Python 3
- Pandas
