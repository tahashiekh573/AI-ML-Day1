# Student Performance Prediction

## Project Overview

This project was completed for Day 4 of the HisabDo AI/ML Internship.

The goal of this project is to predict whether a student will Pass or Fail based on their academic performance.

## Features Used

- Attendance
- Assignment Score
- Midterm Score
- Final Score

## Machine Learning Model

- Logistic Regression

## Project Steps

- Load dataset using Pandas
- Clean the data
- Create Pass/Fail target column
- Split data into training and testing sets
- Train Logistic Regression model
- Make predictions
- Evaluate model using Accuracy, Confusion Matrix, and Classification Report
- Generate visualizations

## Libraries Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## Accuracy

The model achieved an accuracy of **100%** on the current test dataset.
