# Student Performance Analysis

## Overview

This project is developed for Day 3 of the HisabDo AI/ML Internship.

The project uses Python and Pandas to analyze student performance data and Matplotlib to create visualizations.

## Features

- Load student dataset
- Display dataset information
- Calculate average scores
- Find highest and lowest scoring students
- Identify students with attendance below 75%
- Identify students at risk
- Calculate average score by course
- Analyze attendance and final score relationship
- Handle missing values
- Generate charts

## Technologies

- Python
- Pandas
- Matplotlib

## Files

- students.csv
- analysis.py
- README.md
- requirements.txt
- conclusion.md

## How to Run

```bash
python -m pip install -r requirements.txt
python analysis.py
```
